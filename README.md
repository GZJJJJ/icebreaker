# 破冰小子（Icebreaker）

面向主题咖啡馆多人桌的 AI 社交主持设备原型。

## 最终交付目标

做出可展示、可受控试用的完整桌面社交主持原型：参与者自愿加入，经许可用摄像头辅助推荐场景，由用户确认模式和主题；设备简短开场，支持多轮接话与换题，并结合语音活动和获准的视觉线索提供保守的冷场轻提示。交流主体是同桌的人，不是 AI；随时可停播、停止音视频采集/上传或结束活动。

视觉只提供可见线索与可纠正的建议，不推断性别、恋爱关系或内心情绪。恋爱/约会主题由用户主动选择；多人不直接等同于会议。摄像头尚未接通，属于目标能力。

当前语音链路和英文状态屏只是底层基线，不等于产品已经完成。首版允许保留 Gateway，不包含商业售卖所需的量产与运营能力。

详细范围、隐私边界和验收标准见 [产品目标文档](docs/PRODUCT_GOALS.md)。

## 项目目标

### 当前技术基线

- DNESP32S3B V1.1 设备联网
- K0 按键控制录音开始/结束
- Gateway 串联 SenseVoice ASR → DeepSeek LLM → Edge TTS
- ES8311 + 板载扬声器播放
- 播报中本地打断，旧音频清理，下一轮可恢复
- ST7789 状态屏显示联网、聆听、思考、播报、打断和错误状态

### 技术基线验收项（不代表全部已实测达标）

- 连续多轮会话
- 打断后重新录音和回复
- Gateway 断线重连
- 空识别、Provider 失败、超长音频和播放失败恢复
- 本地功放控制正确：蜂鸣器关闭，扬声器播放时开启

### 暂不纳入

- 从画面推断性别、恋爱关系或情绪，以及个人身份识别
- 未经许可的环境拍摄/上传或持续视频监控
- OpenVela 迁移
- 商业后台、计费和门店设备管理
- 免费云服务上的固定低延迟 SLA

## 目录

- `firmware/`：ESP-IDF 固件
- `gateway/`：Python WebSocket Gateway 和 Provider 适配
- `archive/local/`：本机历史研究和大文件归档，不进入 Git
- `tools/`：硬件联调工具
- `gateway/LATENCY.md`：语音链路延迟测量与限制
- `firmware/README.md`：板级构建、烧录和验收说明

## 安全边界

凭据、Wi-Fi 配置、flash dump、构建产物和本地会话文件不提交到仓库。Provider API Key 只从项目根目录本地配置或环境变量读取。

Gateway 不使用系统默认 Python。首次运行 `gateway\bootstrap.ps1`，以后用 `gateway\start.ps1` 或 `gateway\test.ps1`；专用环境固定 Python 3.12.12，不需要调整 Anaconda。

摄像头接口和选型核对见 [CAMERA_SELECTION.md](docs/CAMERA_SELECTION.md)。当前推荐先从 USB-A `HOST` 的 UVC MJPEG 摄像头做主动快照，摄像头尚未接入语音固件。
